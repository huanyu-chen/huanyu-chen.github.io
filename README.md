# Huan-Yu Chen — Academic Profile

A privacy-conscious static academic website generated from explicitly public records only.

## Privacy scope

The site intentionally excludes private evidence, identity documents, certificate numbers,
student records, recommendation letters, unpublished submissions, phone numbers, addresses,
and the source Academic Knowledge Base. It uses no analytics, cookies, external fonts, or APIs.

## Local preview

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

The repository is compatible with GitHub Pages and requires no build step.
